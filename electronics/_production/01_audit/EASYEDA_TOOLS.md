# EasyEDA MCP tools — Phase 0

Checked: 2026-10-29. Source: session `ALL_TOOLS` metadata and read-only EasyEDA MCP responses saved alongside this file.

**101 EasyEDA tools are exposed, all in `mcp__easyeda_pro`. This is EasyEDA Pro, not Standard.** Server/extension report 1.6.0, bridge reports 1.0.0, active profile is `pro`, connection is healthy. These version numbers are not the EasyEDA editor build. The exact editor build is **UNVERIFIED**: the status responses omit it.

No exposed tool accepts KiCad/EasyEDA files for project import. Bridge capabilities include `project.open`, `api.call`, and `pcb.rebuildCopper`, but those are not callable tools exposed in this session. Runtime API discovery is read-only; it reports 84 API classes, including existing-project/document open and routing-result imports, not a general KiCad-project importer. A schematic-to-PCB sync is not a file import. No profile/configuration change, project open, import, placement, routing, refill or export was attempted.

The table lists every tool separately. Action means advertised capability, not proof of successful use. No tool has a verified external-design import format in this exposed set. Full argument schemas and descriptions are preserved in [EASYEDA_TOOL_CATALOG_RAW.json](EASYEDA_TOOL_CATALOG_RAW.json). Tool descriptions provide additional limits. For any later board mutation, the user's phase gates and CHG approval override a tool's ability to write.
